# Pandas learning-by-doing refresher

Start with **`pandas_learning_by_doing.ipynb`**. It is a self-contained, one-day course with a deterministic commerce dataset and hands-on exercises from foundations through a capstone.

Use **`pandas_learning_by_doing_solutions.ipynb`** only after making an honest attempt. It mirrors the learner notebook and replaces every starter cell with a worked solution.

## Run it

Open the learner notebook in Jupyter, VS Code, Cursor, or another notebook environment with Python, pandas, NumPy, Matplotlib, and PyArrow installed. Run the setup cells, then work top to bottom.

The core exercises should take roughly 6–8 focused hours. Stretch exercises can roll into a second session.

## Rebuild the notebooks

`build_pandas_refresher.py` is the source generator. Run it with Python to regenerate both notebooks after editing the course content.
